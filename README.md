# Flutter Interview Hub

An interactive Flutter interview study guide with 50 questions, searchable topic navigation, browser routes, progress tracking, bookmarks, and code examples.

## Run locally

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
```

GitHub Pages deployment is configured through `.github/workflows/pages.yml`. Pushes to `main` build the Vite app and publish the `dist` folder. The repository Pages setting must use **GitHub Actions** as its source.
